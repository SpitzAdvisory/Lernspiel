# Unterlagen zu SPITZ Lernen

Dieser Ordner sammelt die Dokumente zur App. Dateien nach dem Schema
`yyyymmdd_Name_Vx`; das Datum steht über der Versionsnummer.

## Bestand

| Datei | Inhalt |
|---|---|
| `20261031_SPITZ-Lernen_Stand-und-Sicherung_V1.md` | Bestand, die vier Sicherungsorte, Tabelle aller 54 Fassungen, Befehl zum Zurückholen |
| `20261031_SPITZ-Lernen_Architektur-heute_V1.md` | Aufbau der App heute, in gewöhnlichen Worten, mit fünf Bildern |
| `20261031_SPITZ-Lernen_Architektur-kuenftig_V1.md` | Die fünf geplanten Änderungen, mit zwei Bildern |

## Lesereihenfolge

Zum Einstieg `Architektur-heute`, Abschnitt 2 und 3. Für die Frage, wie eine
verlorene Fassung zurückkommt, `Stand-und-Sicherung`, Abschnitt 3. Für die
anstehende Entscheidung `Architektur-kuenftig`, Abschnitt 9.
